# SOP: Design (Stylize)

**Goal**: Apply the "Glaido" brand identity to the Shabtai XP Dashboard.

## 1. Color Palette
- **Lime Green** (Primary / Highlight): `#BFF549`
- **Black** (Background / Text / Structure): `#000000`
- **White** (Background / Text / Balance): `#ffffff`

**Usage Rules**:
- **Backgrounds**: High contrast. Dark mode preferred for "Tech-Forward" feel (Black bg, White text, Lime accents) OR Clean Light mode (White bg, Black text, Lime accents). given "Glassmorphism" history, we will aim for a **Dark Mode** "Hedge Fund" aesthetic if not specified otherwise, using Black `#000000` as base.
- **Accents**: Progress bars, active states, and key buttons use **Lime Green**.

## 2. Typography
- **Headings**: `Inter Display` (System fallback: `Inter`, `sans-serif`)
  - *Weights*: Regular, Medium, Bold.
- **Body**: `Inter`
  - *Weights*: Regular, Bold.

## 3. UI Components (Streamlit/Web)
- **Buttons**: Rounded corners, no drop shadows (Flat aesthetic).
- **Cards**: Minimal borders, high contrast.
- **Logo**: Round "G" / Text "Glaido" (if applicable) or "Shabtai XP" using the brand font.

## 4. Layout
- **Structure**: Open, accessible, "flow".
- **Spacing**: Generous whitespace (or blackspace).
